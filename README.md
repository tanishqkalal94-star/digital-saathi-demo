# Digital Saathi — Website Demo

A responsive, static website introducing the Digital Saathi secure document wallet concept. Built with plain HTML, CSS, and JavaScript and configured for automatic deployment to GitHub Pages.

> **Concept demo only.** This is not a government website or production document service. It does not connect to government platforms, verify documents, upload files, or save user data. Use fictional information only; never enter real Aadhaar, financial, health, education, or other sensitive personal information.
